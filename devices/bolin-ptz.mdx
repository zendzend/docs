The **Bolin PTZ** device controls Bolin PTZ cameras, so a rundown item can reframe a shot or drop back to a stored preset.

## Connection

Provide the camera's **host**, **port**, and its **camera address**, which is 1 when controlling over IP.

## Commands

### Movement

| Command | What it does |
| --- | --- |
| Drive | Moves the head in one of eight directions at a pan and tilt speed |
| Stop | Stops pan and tilt movement |
| Go to position | Moves to an absolute pan/tilt position, where 0 is centre |
| Move relative | Moves by a signed pan/tilt offset from where it is now |
| Home | Returns the head to its home position |
| Recalibrate | Recalibrates the pan/tilt head |

### Presets

| Command | What it does |
| --- | --- |
| Recall preset | Recalls a stored preset |
| Store preset | Stores the current position as a preset |
| Clear preset | Clears a stored preset |

### Picture and power

| Command | What it does |
| --- | --- |
| Zoom | Zooms tele or wide at a speed, stops zooming, or moves to an absolute position |
| Focus | Focuses far or near at a speed, moves to an absolute position, toggles auto focus, or runs a one-push auto focus |
| Exposure | Sets the auto-exposure mode |
| Backlight compensation | Turns backlight compensation on or off |
| White balance | Sets the mode, or runs a one-push white balance |
| Power | Powers the camera on or puts it into standby |

Manual focus commands apply only when auto focus is off.

## State and triggers

The device reports its connection state, vendor and model, and power state, and raises a trigger when the connection changes.
