The **MA Lighting grandMA3** device drives a [MA Lighting grandMA3](https://www.malighting.com/grandma3/) lighting console (or onPC) over the network.

## Connection

The agent sends OSC to the console over the network. Provide the **console IP** and the **OSC port** (commonly **8000**) configured on the console's OSC line. Set the **fader range** to the full-scale value shown in the console's OSC settings so fader levels scale correctly, and set an **OSC prefix** if one is configured on the console.

<Note>
  Enable and match the console's OSC input settings (port, prefix, and fader range). If they do not match, the console silently ignores incoming commands.
</Note>

## Commands

The grandMA3 device supports playback operations, including:

- **Press an executor key** (go, flash, and so on, per its console assignment)
- **Set an executor fader** level
- **Transport** an executor — go, pause, or off
- **Select an executor page**
- **Call a macro** by number or name
- **Send a console command** line

## State

The device reports its connection state. This driver sends commands to the console and does not poll it for state or raise triggers.
