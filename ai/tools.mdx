The Fabl MCP server offers 97 tools, grouped below by area. The **Asks first** column shows whether Claude asks for your approval before each call: tools that only read run without asking, and every tool that changes something or acts on your studio asks first. Each tool also checks your [role and permissions](/team/roles-and-permissions) before it runs. To connect an assistant, see [Connect an assistant](/ai/connect).

## Account and utilities

| Tool | What it does | Asks first |
| --- | --- | --- |
| `get_current_user` | Shows who the assistant acts as: your name and email, the organization, your role and your permissions | No |
| `get_current_datetime` | Gets the current date and time | No |

## Spaces and folders

| Tool | What it does | Asks first |
| --- | --- | --- |
| `list_spaces` | Lists or searches spaces | No |
| `create_space` | Creates a space | Yes |
| `update_space` | Changes a space's title or icon | Yes |
| `delete_space` | Permanently deletes a space and everything in it | Yes |
| `create_folder` | Creates a folder in a space or another folder | Yes |
| `update_folder` | Changes a folder's title or icon | Yes |
| `delete_folder` | Permanently deletes a folder and everything in it | Yes |

## Pages

| Tool | What it does | Asks first |
| --- | --- | --- |
| `list_pages` | Lists or searches pages, optionally within a space or folder and by date | No |
| `search_pages` | Searches pages by title and content | No |
| `search_workspaces` | Finds which spaces contain a word, across every title and value | No |
| `get_page_content` | Reads a page's full content: every block, field label and value | No |
| `create_page` | Creates a page in a space or folder, optionally dated | Yes |
| `update_page` | Changes a page's title, icon, date or time | Yes |
| `duplicate_page` | Copies a page with all its content | Yes |
