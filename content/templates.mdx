A **template** is a full-page blueprint. Creating a page from a template starts you off with a ready-made block structure and default values, so every rundown or script of the same kind begins consistent.

## Create a template

1. Open the **Templates** section and click **New template**.
2. Build the page structure you want to reuse — add fields, media, containers, components, and any default content.
3. Give it a title and icon, and optionally assign it to specific spaces.

## Create a page from a template

1. In a [space or folder](/content/spaces-and-folders), create a new page and choose **From template**.
2. Select a template.
3. A new, independent page is created with the template's structure and defaults. Changes to the template don't affect pages already created from it.

## Templates vs. components

A **template** produces a whole new [page](/content/pages-and-blocks). A [component](/content/components) is added as a block _inside_ an existing page. Reach for a template when you repeat an entire page layout, and a component when you repeat a piece within pages.

<Note>
  Creating and editing templates requires the templates management permission. See [Roles and permissions](/team/roles-and-permissions).
</Note>
